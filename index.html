Everything in one panel

All the hosting tools — without the hosting bill

The features you know from cPanel, Plesk and aaPanel, rebuilt around how developers ship today: Git, environment variables, processes and safe rollbacks.

One page per website

Domains, code, deployments, .env, the app process, database, backups and logs of a site — together on one page. No more hunting through ten menus.

Push-to-deploy with rollback

Webhooks for GitHub, GitLab, Gitea and Bitbucket. Every deployment keeps its log, and any earlier commit is one click away.

Builds detected for you

Free SSL that renews itself

Let's Encrypt certificates with HTTP→HTTPS redirect, a live DNS check before issuing, and automatic renewal.

Node.js & Python apps

Apps run under PM2 with crash restarts. After each deploy AutsPanel checks the app really answers on its port.

PHP, Laravel & WordPress

Databases

Firewall that never locks you out

SSH & deploy keys

How it works

From a fresh VPS to a live site in minutes

AutsPanel is a lightweight Node.js service that drives the standard tools you would use by hand — nginx, PM2, PHP-FPM, MariaDB, certbot, UFW — and keeps them consistent. Read the architecture →

Install

Run the installer on a fresh Ubuntu or Debian server and open the dashboard on port 9090.

Create a website

Paste a Git URL or pick WordPress. Folder, port, build and start commands are suggested for you.

Push your code

A webhook deploys every push to your branch. Watch the live log; roll back with one click.

Relax

Certificates renew, backups run on schedule, crashed apps restart and you get an alert if anything fails.

Deployments

Deploy on push. Roll back in one click.

Connect GitHub, GitLab, Gitea or Bitbucket with a signed webhook. Every deployment runs as a job with a step-by-step checklist and full log, and is kept in the history.

  • Pull, build, restart and health-check in one pipeline
  • Editable deploy script with your site's PHP, Node and port
  • Roll back to any earlier commit — the next push moves forward again
  • Discord and email alerts for successful and failed deploys
New website

Paste a repository. Everything else is filled in.

AutsPanel inspects your repository before creating anything: it recognises Next.js, React, Laravel, PHP, Python and static sites, and suggests the build command, start command, web root, a free port and the right PHP version.

  • Folder /var/www/<name> and port chosen automatically — all editable
  • Live DNS check tells you when HTTPS can be issued
  • Database and .env credentials created in the same step
  • One-click WordPress with admin account, no setup screen
Domains & SSL

Domains, HTTPS and nginx without the config files

Add domains and aliases, see whether each one already points to your server, and issue a free Let's Encrypt certificate. Every nginx change is tested with nginx -t and rolled back automatically if it would break anything.

  • Automatic HTTPS redirect and renewal
  • Take a site offline or change its web root and upload limit
  • Full nginx config editor for advanced setups
Insights

Know what your sites are doing

Requests, visitors, bandwidth, top pages, referrers and 404s per website — straight from the nginx access log, no tracking script needed. App output and error logs are one click away.

FAQ

Questions, answered

Is AutsPanel really free?

Yes. AutsPanel is open source under the MIT license. There is no paid tier, no per-account or per-domain license, and no feature behind a paywall. You only pay for your VPS.

Which servers does it run on?

Ubuntu 20.04, 22.04 and 24.04 LTS and Debian, on any VPS provider (Hetzner, Contabo, DigitalOcean, Linode, AWS Lightsail, Vultr…). It needs root access; 1 GB of RAM is enough for the panel and a few small sites, 2 GB or more is recommended for Node.js builds.

Can it host Node.js, Next.js and React apps?

Yes — that is what it is built for. Node.js and Next.js apps run under PM2 behind nginx; React, Vite and Vue apps are built on deploy and served as static files with a single-page-app fallback, so client-side routes never 404.

Does it support PHP, Laravel and WordPress?

Yes. Install PHP versions from 5.6 to 8.x side by side, deploy Laravel with Composer and migrations, and install WordPress in one click with its own database.

Can I move my sites from cPanel or aaPanel?

Yes. Create the website in AutsPanel, upload your files and import your database dump, then switch the DNS record. The migration guide walks through it step by step.

How do I update AutsPanel?

When a new version is published, the panel shows an update notice. Updating pulls the new version, installs dependencies, checks every file and rolls back automatically if anything fails.

Who makes AutsPanel?

AutsPanel is developed by Aashish Timalsina and published by auts-tech as a free, community project. Contributions are welcome on GitHub.
