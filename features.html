Features

Everything you need to run websites on a VPS

Hosting, deployments, databases, SSL, backups and security in one open-source panel. Here is what AutsPanel does — all of it free.

Websites

Every site and app, managed in one place

A website in AutsPanel joins everything that belongs to it: the domains served by nginx, the Git repository and its deployments, the .env file, the PM2 process or PHP version, the database, backups, cron jobs and logs. Open it and you see its health, a setup checklist and quick actions.

  • Overview with live status, commit, disk usage and database size
  • Setup checklist: domain, HTTPS, deploy, webhook, backups
  • Existing nginx sites can be imported with one click
  • Delete a site cleanly — choose whether files and database go too
Stacks

Node.js, Next.js, React, Laravel, PHP, WordPress, Python

Choose a starting point — Git, WordPress, an empty site or a reverse proxy — and AutsPanel prepares the right nginx template and runtime. Front-end apps get a single-page-app fallback, PHP sites their own PHP-FPM version, Node and Python apps a PM2 process on a free port.

  • React / Vite / Vue built on deploy and served from dist or build
  • Laravel: composer install, migrations, config/route/view caches, APP_KEY
  • WordPress installed with WP-CLI, its own database and admin user
  • Reverse proxy to Docker containers or any service on a port
Deployments

Git deployments with history, logs and rollback

Each deployment pulls your branch, runs your deploy script, fixes file permissions for PHP, restarts the app and checks that it answers. Missing tools such as Composer or PM2 are installed automatically the first time they are needed.

  • Signed webhooks for GitHub, GitLab, Gitea and Bitbucket
  • One queued deploy when pushes arrive during a running deploy
  • Roll back to any successful commit
  • Option to discard changes made on the server (git reset --hard)
Environment

Edit .env without breaking it

Edit environment variables in a table with secrets masked, or as a raw file. Comments and order are kept. Missing keys from .env.example are pointed out, and one click restarts the app or rebuilds Laravel's config cache.

  • Secrets hidden until you reveal them
  • Database credentials written for you when a database is created
  • Save & restart / Save & cache config
Apps

Processes that stay up

Node.js, Next.js and Python apps run under PM2, restart automatically if they crash and come back after a reboot. See status, uptime, memory, CPU and restarts, read the app's output and error logs, and change the start command or port — nginx follows automatically.

  • PORT passed to your app, nginx proxy updated with it
  • Crash detection after deploys shows the last error lines
  • Start, stop and restart from the website page
PHP & Composer

Every PHP version you need, side by side

Install PHP 5.6 to 8.x from the ondrej/sury repositories, switch a site's version from its PHP tab, manage extensions and common php.ini settings. Composer is installed with checksum verification and can run install, update, require and more in any project with the PHP version you pick.

  • Per-site PHP-FPM version
  • Composer commands with live output
  • Laravel scheduler as a switch
And more

The rest of the toolbox

Databases

Create databases and users, grant privileges, browse tables, run SQL, import and export dumps.

Backups

Google Drive, S3 or SFTP; per-site schedules; whole-server snapshots; retention cleanup.

Firewall

UFW rules, quick rules for web and mail, block an IP — SSH always stays open.

SSH keys

Authorized login keys and a deploy key for private Git repositories.

File manager

Browse, edit, upload, zip/unzip, permissions and ownership.

Terminal

Full root shell in the browser over an authenticated WebSocket.

Email hosting

Mailboxes, aliases, DKIM and a DNS checker, with optional Roundcube webmail.

Monitoring

CPU, RAM, disk, processes, services and ports — with Discord and email alerts.
