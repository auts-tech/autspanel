About

Free hosting software, made in the open

AutsPanel exists because running your own server should not mean paying a license per website. It is developed by Aashish Timalsina and published by auts-tech under the MIT license.

The project

AutsPanel started as a deploy and backup manager for VPS servers and grew into a complete control panel: websites, Git deployments, SSL, databases, PHP, email, backups and security. It is built to stay simple — a single Node.js service that drives standard Linux tools you already trust.

It is free for everyone, for any use, with no paid edition. If it helps you, the best thanks is a star, a bug report or a pull request.

Contributing

AutsPanel is plain Node.js (Express) and vanilla JavaScript — no build step. Fork the repository, run ./start.sh locally, and open a pull request. Documentation fixes are just as welcome: every docs page has an “Edit this page” link.
