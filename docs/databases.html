Databases

On this pageInstall or connect MariaDBDatabases, users and privilegesA website's databaseLink an existing databaseImport and export

AutsPanel manages MariaDB or MySQL on the server — and connects each database to the website that uses it, so credentials and backups stay in one place.

Install or connect MariaDB

On the Databases page, click Install MariaDB if no database server is installed. If MySQL or MariaDB is already there, click Connect automatically (it uses the root socket login on Ubuntu/Debian) or enter an admin user and password.

If MySQL's password policy (validate_password) is enabled, AutsPanel reads its rules and generates passwords that pass them. When a password you type is rejected, the message tells you the minimum length and which characters are required.

Databases, users and privileges

  • Create databases and users, change passwords, and grant or revoke privileges.
  • Browse tables and rows, and run SQL in the console.
  • The Website column shows which website uses each database, and Link to website connects one.

A website's database

When you create a Laravel or WordPress website with Create a database ticked, AutsPanel creates a database and a user with a random password and writes them to .env (DB_DATABASE, DB_USERNAME, DB_PASSWORD) or wp-config.php. You can also create one later on the website's Database tab.

Link an existing database

Already have a database — for example one you imported from another host? Open the website's Database tab. AutsPanel reads the site's configuration and shows the database it finds:

  • .env: DATABASE_URL (mysql://…) or DB_DATABASE/DB_NAME with DB_USERNAME and DB_PASSWORD;
  • wp-config.php: DB_NAME, DB_USER and DB_PASSWORD.

If that database is on this server, click Link to connect it. You can also choose any database under Use an existing database, pick its user and optionally its password. Once linked, the database is included in the website's backups and shown on its overview. Unlink (keep the database) only removes the connection; Delete database and user drops both.

Import and export

Export any database as a compressed .sql.gz dump, or import a .sql / .sql.gz file — for example a dump from cPanel's phpMyAdmin. For very large dumps, upload the file with the File manager and import it from the Terminal:

gunzip < /root/site.sql.gz | mysql site_db
