AutsPanel documentation

AutsPanel is a free, open-source hosting control panel for a single Ubuntu or Debian VPS. These guides take you from a fresh server to production websites with HTTPS, Git deployments and backups.

Installation

Requirements, the installer, first login and HTTPS for the panel.

Websites

Create Node.js, Next.js, React, Laravel, PHP, WordPress and static sites.

Git deployments

Deploy on push, deploy scripts, history and rollback.

How it works

The architecture: nginx, PM2, PHP-FPM, MariaDB, certbot and jobs.

What AutsPanel manages

Everything on the server is organised around websites. A website is one site or app with its domains, code, deployments, .env, app process, PHP version, database, backups and logs. Around that, AutsPanel manages the server itself:

  • Hosting: SSL certificates, PHP versions and Composer, MariaDB/MySQL databases, email hosting, a file manager and a web terminal.
  • Automation: scheduled backups to Google Drive, S3 or SFTP, cron jobs, push-to-deploy webhooks and alerts.
  • Security: the UFW firewall, SSH login keys and deploy keys, systemd services and open ports.
