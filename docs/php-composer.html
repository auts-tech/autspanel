PHP & Composer

On this pageInstall PHP versionsChoose a website's PHP versionExtensions and php.iniComposerLaravel schedulerFAQ

Run old and new PHP applications on the same server: every website can use its own PHP-FPM version.

Install PHP versions

On the PHP & Composer page, click Add repository once. It adds the ondrej/php repository on Ubuntu or packages.sury.org on Debian. Then install any version from 5.6 to 8.x with the common extensions. Several versions run side by side, each with its own FPM service.

Choose a website's PHP version

New PHP, Laravel and WordPress websites use the newest installed version — or the one matching the php requirement in composer.json. Switch at any time on the website's PHP tab; nginx is updated and tested automatically.

Extensions and php.ini

Enable or disable extensions per version and edit common php.ini settings such as memory_limit, upload_max_filesize, post_max_size and max_execution_time. You can also choose the default php command for the terminal.

Composer

The Composer section installs Composer (with its checksum verified) and keeps it updated. Run install, update, require, remove, dump-autoload and more in any project folder, with the PHP version you choose and live output. Deployments run composer install automatically for PHP sites.

Laravel scheduler

Turn on Laravel scheduler on a Laravel website's PHP tab. AutsPanel adds the cron entry that runs php artisan schedule:run every minute with the site's PHP version.

Frequently asked questions

Which PHP versions are supported?

Any version the ondrej/php (Ubuntu) or sury.org (Debian) repositories provide for your release, typically PHP 5.6 up to the latest 8.x.

My PHP site shows 502 Bad Gateway. What now?

The site's PHP-FPM service is not running. Start it on the PHP & Composer page or switch the site to an installed version on its PHP tab.
