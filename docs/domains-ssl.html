Domains & SSL

On this pageAdd domainsPoint DNS to the serverIssue HTTPSWeb server settingsEdit the nginx config

Domains, HTTPS and the web server for each website live on its Domains & SSL tab.

Add domains

Enter one domain per line. The first is the primary domain; the others are aliases, such as www.example.com. A domain can belong to only one website. Saving updates the nginx server block and tests it before applying.

Point DNS to the server

At your DNS provider, create an A record (and AAAA for IPv6) for each domain with the server's IP address. The tab shows each domain's current DNS status — points here, points elsewhere or no DNS record. If you use Cloudflare's proxy, the check shows Cloudflare's address; issue the certificate with the proxy turned off, or use Cloudflare's “Full (strict)” mode.

Issue HTTPS

When the domains point to the server, click Enable HTTPS. AutsPanel runs certbot for all the website's domains, turns on the HTTP → HTTPS redirect, and certbot renews the certificate automatically. The SSL / TLS page lists every certificate on the server with its expiry date.

Let's Encrypt limits how many certificates you can request for the same domain per week. If issuing fails, fix the DNS first instead of retrying many times.

Web server settings

  • Online / offline — take a site offline without deleting it.
  • Web root — the folder nginx serves, for example public or dist.
  • Upload limit — nginx's client_max_body_size, for large uploads.

Edit the nginx config

For advanced setups, open Edit nginx config. The editor checks your change with nginx -t and restores the previous file if the check fails, so a typo never takes your other sites down.
